# Data Sheet

## Общая информация

**Датасет:** PlantVillage. Автор выбранной модели ссылается на его производную версию New Plant Diseases Dataset на Kaggle.

**Назначение:** классификация листьев по культуре и болезни либо здоровому состоянию.

## Состав данных

- **Исходный PlantVillage:** 54 306 изображений, 14 культур.
- **Выбранная модель:** 38 классов культуры и состояния.
- **Объём производной версии Kaggle:** 87900 изображений, 14 культур.
- **Тип данных:** изображения листьев с метками классов.
- **Логические поля в проекте:** `image` — изображение; `label` — класс.

## Источники

- [Исходный PlantVillage](https://github.com/spMohanty/PlantVillage-Dataset).
- [Версия Kaggle, указанная автором модели](https://www.kaggle.com/datasets/vipoooool/new-plant-diseases-dataset).

## Получение данных

Фотографии здоровых и поражённых листьев собраны для исследований распознавания болезней растений. Подробная процедура сбора и разметки производной версии в Model Card модели не указана.

## Предобработка

Точная обучающая предобработка в Model Card не указана. В проекте планируется преобразование в RGB, изменение размера и нормализация процессором выбранной модели.

## Ограничения

- Ограниченный набор культур и болезней.
- Возможное снижение качества на полевых фотографиях.
- Похожие снимки одного листа и их производные могут вызвать утечку между обучением и оценкой; их следует помещать в одну часть выборки.

## Использование в проекте

Планируется оценка качества и, при необходимости, дообучение. Для независимой проверки нужно исключить пересечения с обучающими данными модели и дополнительно использовать полевые фотографии.
