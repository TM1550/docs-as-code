# Model Card

## Общая информация

- **Модель:** `linkanjarad/mobilenet_v2_1.0_224-plant-disease-identification`.
- **Автор:** linkanjarad, Hugging Face.
- **Задача:** определение культуры и состояния листа по изображению; 38 классов.
- **Архитектура:** MobileNetV2.
- **Язык:** не применимо.
- **Обучающие данные:** версия PlantVillage — New Plant Diseases Dataset на Kaggle.
- **Лицензия:** `other`; условия использования требуют уточнения.

## Источники

- [Модель и метрики](https://huggingface.co/linkanjarad/mobilenet_v2_1.0_224-plant-disease-identification).
- [Обучающий датасет на Kaggle](https://www.kaggle.com/datasets/vipoooool/new-plant-diseases-dataset).

## Использование в проекте

В проекте «Классификатор болезней растений» фотография поступает через `POST /classifications`. API передаёт её модели, сохраняет результат и показывает пользователю класс и оценку уверенности. История и отдельный результат доступны через `GET /classifications` и `GET /classifications/{id}`. Это планируемое поведение сервиса.

## Входные данные

RGB-изображение листа. Сервис принимает JPG и PNG. Размер и нормализация задаются процессором из репозитория модели.

## Выходные данные

Метка класса и score, отображаемый в процентах. Score не гарантирует правильность определения.

## Метрики качества

По данным автора: **accuracy — 95,41%**, **cross-entropy loss — 0,15** на оценочной выборке.

## Ограничения

- **Указано автором:** модель не заменяет диагноз специалиста.
- Поддерживаются только классы, представленные в модели.
- **Потенциальное ограничение для нашего проекта:** качество может снижаться на полевых, размытых или плохо освещённых фотографиях.
- **Потенциальное ограничение для нашего проекта:** высокий score возможен и при ошибке; калибровка автором не описана.

## Не рекомендуется использовать

Для окончательного диагноза, автоматического назначения препаратов и дозировок, а также для неподдерживаемых культур и болезней.
