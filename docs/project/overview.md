# Классификатор изображений

Сервис предназначен для автоматического определения категории изображения.
Пользователь загружает фотографию, система передаёт её ML-модели, а затем
показывает предсказанную категорию и уверенность модели.

Основные пользователи:
- пользователь

Основные функции:
- загрузка изображения;
- классификация изображения;
- просмотр результата классификации;
- просмотр истории классификаций.

## Комплект документации

1. **Описание проекта** — для команды и пользователей, чтобы понимать назначение сервиса.
2. **Требования** — для разработчиков и тестировщиков, чтобы зафиксировать функции и критерии приёмки.
3. **Архитектура системы** — для разработчиков, чтобы понимать состав компонентов и связи между ними.
4. **Документация API** — для фронтенда и внешних интеграций, чтобы вызывать сервис классификации.
5. **Документация ML-модели** — для ML-инженеров, чтобы знать модель, метрики, ограничения и порядок обновления.
6. **Руководство пользователя** — для конечных пользователей, чтобы загружать изображения и понимать результаты.
