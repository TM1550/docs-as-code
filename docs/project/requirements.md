# Требования

## User Stories

### US-01. Загрузка изображения

Как пользователь,  
я хочу загрузить изображение,  
чтобы получить его категорию.

Критерии приёмки:
- система принимает изображения в форматах JPG и PNG;
- после загрузки изображение отображается в интерфейсе;
- при неподдерживаемом формате пользователь видит сообщение об ошибке.

### US-02. Классификация изображения

Как пользователь,  
я хочу автоматически получать категорию изображения,  
чтобы понять, что на нём изображено.

Критерии приёмки:
- система передаёт загруженное изображение ML-модели;
- после обработки отображается категория изображения;
- отображается уверенность модели в процентах;
- если модель не может обработать изображение, пользователь видит сообщение об ошибке.

### US-03. Просмотр истории классификаций

Как пользователь,  
я хочу видеть историю своих классификаций,  
чтобы вернуться к предыдущим результатам.

Критерии приёмки:
- система сохраняет загруженные изображения и результаты классификации;
- пользователь видит список последних классификаций;
- можно открыть предыдущий результат классификации.

## Use Case

### UC-01. Классификация изображения

**Актор:** пользователь.  
**Цель:** определить категорию изображения.  
**Предусловие:** пользователь открыл сервис и выбрал изображение.

**Основной сценарий:**
1. Пользователь загружает изображение.
2. Система проверяет формат файла.
3. Система передаёт изображение ML-модели.
4. ML-модель выполняет классификацию.
5. Система получает категорию и уверенность модели.
6. Система отображает результат пользователю.

**Альтернативный сценарий:**
Если формат не поддерживается или модель не может обработать изображение,
система показывает сообщение об ошибке и предлагает загрузить другое изображение.

**Результат:** пользователь видит категорию изображения или сообщение об ошибке.
