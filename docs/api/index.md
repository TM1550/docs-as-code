# API

API предоставляет доступ к функциям ИИ-сервиса классификации изображений.

## Основные операции

- `POST /classifications` — классифицировать изображение;
- `GET /classifications` — получить историю классификаций с фильтрацией по периоду и классам;
- `GET /classifications/{id}` — получить результат классификации по ID.

## Спецификация

Полное описание API находится в файле [`openapi.yaml`](./openapi.yaml).

Для просмотра в интерактивном виде откройте `openapi.yaml` в
[Swagger Editor](https://editor.swagger.io/).
